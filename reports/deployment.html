Deploy your dashboard

The dashboard is a static website. No API key, database, server function or paid service is required to run the included demo. All fonts and assets are local or system-provided.

Fastest path: upload the ready build

  1. Unzip relate-dashboard-deploy.zip.
  2. Upload its contents to any static web host. index.html must be at the site's root.
  3. Open the hosted URL. Check all six views and a report download.

The archive contains the dashboard, demo data, model, creative assets, PDFs and documentation. It can also be hosted in a subdirectory because asset paths are relative.

Build from source

Unzip relate-complete-project.zip and open a terminal in relate-analytics.

npm run build
npm start

Open http://127.0.0.1:5174. The build needs Node.js 22+ and the preview command needs Python 3.10+. There are no npm dependencies to install. You can also serve dist/ with any static web server. Double-clicking index.html will not work because browsers restrict local-file fetches.

Use real data

Open Data Studio and import CSV exports or a JSON bundle. The imported data is temporary browser memory. Export the full JSON bundle before refreshing or leaving. No data is transmitted to a backend.

To replace the hosted default dataset, run the Python pipeline, review its output, rebuild and redeploy:

python3 python/pipeline.py --input /path/to/exports --output data/clean --source user_import
npm run build

Files in a public static deployment are public. Use synthetic or appropriately anonymized records as the bundled default. Local imports are not uploaded. The PDF strategy report and content playbook describe the original demo; after importing new data, use “Export this analysis” in Strategy to download the current results.

Verification

npm test

Tests cover cleaning, invalid imports, zero denominators, sentiment parity between Python and JavaScript, exact permutation behavior, forecasts and CSV round-trips. Browser checks are documented in the project validation report.
