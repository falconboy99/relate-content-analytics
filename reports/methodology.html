Methodology & data dictionary

Demonstration, not a real campaign. The bundled records are generated with seed 42. No social accounts were scraped, no content was published, and no real audience outcomes are claimed.

Architecture

CSV exports → validation and cleaning → trained NLP classification → structured JSON → browser analytics → strategy and downloadable reports. The Python pipeline and the browser importer use the same schema and model. The dashboard has no external runtime dependencies, trackers or account credentials.

Metrics

  • Engagement: (likes + reported comments + shares + saves) / total post reach. Weighted by denominators, not a mean of post percentages.
  • Weighted viral score: 100 × (3 × shares + 2 × saves + likes) / reach. Project-defined weights, not a validated virality probability or reproduction coefficient.
  • Relatability: model-labeled Relatable comments / analyzed comments. Neutral includes questions, criticism and non-relatable reactions, not just neutral emotional valence.
  • Save-to-share ratio: saves / shares. Undefined at zero shares.
  • Growth: sum of post-attributed follower gains. The chart is cumulative within the selected publication cohort. It is not net account growth.
  • Retention: view-weighted mean of retention_rate.
  • Comment coverage: analyzed comments / reported comments. It can exceed 100% if mismatched export windows are supplied; investigate before interpretation.
  • Zero denominators display “—”. Missing numeric inputs are rejected rather than replaced with zero.

Weekly trends CSV (optional)

Columns: topic,week,index,source. Use one row per topic and week. week is YYYY-MM-DD, index is a number in [0,100]. Keep the same normalization, geography and source for an entire series; preserve those settings in your source notes. The importer does not fetch external trend services.

Import and cleaning

Import one JSON bundle with meta, posts, comments, trends, or upload CSV files together in Data Studio. All files stay in browser memory and reset on refresh. Export Full JSON to preserve the imported campaign. Limits: 15 MB per file, 10,000 posts and 50,000 comments. Identical IDs are deduplicated; conflicting IDs fail atomically. The previous dataset stays active on failure. Dynamic text is HTML-escaped and CSV exports escape formula-leading text.

Use ISO dates and decimal points without thousands separators. Do not replace missing platform metrics with zero. Map only supported measurements, or extend the schema to preserve unavailable values before making platform comparisons. Header-only templates are provided in data/templates/ in the full source package.

The NLP model

Multinomial naive Bayes with word unigrams and bigrams, additive smoothing α=1, equal learned class priors from a balanced corpus and decision threshold 0.5. The model has 120 authored training examples and 36 fixed, separately authored test examples. Training and evaluation comments are not campaign comments. No external data or model downloads are required.

Accuracy: 88.9%; Relatable precision: 85.0%; recall: 94.4%; F1: 0.895. Confusion matrix: 15 true Neutral, 3 false Relatable, 17 true Relatable, 1 false Neutral. The small authored holdout is not a real-world benchmark. The four errors are preserved in evaluation.json.

English only. Negation, sarcasm, mixed-language content, unfamiliar vocabulary and correlated templates are limitations. The posterior score is not calibrated. Comments with score within 0.2 of 0.5 or less than 35% known features are flagged for review. An input with no recognized English features receives Neutral, score 0.5 and review=true. High scores can still be wrong.

Statistical methods

Intervals: 95% Wilson intervals for model label proportions. They omit classification error and comment clustering. They are descriptive, not proof of audience-wide differences.

A/B: one A and one B for each experiment ID, with matching content_id, topic, platform, format, duration and observation window. Outcome is shares/reach. Pair differences are equally weighted. At least three pairs are required. A two-sided sign-flip permutation test enumerates all assignments up to 16 pairs, then uses 10,000 seeded samples with a plus-one correction. The 95% interval is a 2,000-resample percentile bootstrap over pairs. The test and interval use different approximations and can disagree near a threshold; the preselected permutation p-value drives the displayed conclusion. No multiple-outcome testing is performed.

Forecast: OLS interest index against elapsed days, extrapolated seven days and clipped to [0,100]. At least four weekly observations. A last-point backtest is an error diagnostic, not a calibrated confidence interval. Platform filters do not apply to topic-level external trends.

Recommendations: rank topics by the fraction of analyzed comments labeled Relatable. Show observed highest-scoring post format as a candidate for testing, not an optimum. Duration, caption and posting-time causal effects are not identifiable in this demo. Organic data is observational.

Scope relative to the brief

The project implements performance ingestion, weighted virality metrics, NLP, matched A/B comparisons, recommendations, interactive visualization and trend extrapolation. It uses a deployable browser dashboard instead of Power BI/Tableau/Streamlit. CSV export ingestion is implemented; live authenticated social APIs and scheduling are not connected. Video scripts and finished social cards are supplied; video filming, publication and real campaign measurement remain future fieldwork.
